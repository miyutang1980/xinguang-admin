# 登入、導向與接送排程回歸測試

執行 `node tests/browser/run.mjs`，需安裝 Playwright 與 Chromium。全部網路請求由測試攔截，僅使用虛構帳號、學生與排程，不呼叫正式 Gateway 或写入正式資料。

## 2026-09-22 修正範圍

- 自動登入只啟動一次；登入按鈕連點共用同一請求。
- 重複初始化不再切回儀表板，登出後忽略舊登入回應。
- 學生主檔、當期與歷史指派的實際入口、資料欄位與切換。
- 開班資訊的延遲成功或失敗不能覆蓋接送或學生頁面。
- 帳號管理與延遲模組的舊渲染工作不能覆蓋新頁面。
- 接送新增日期五條路線、單一路線、重複日期阻擋與讀回確認。
- 讀取失敗停用新增，重試入口有效。
- 接送請求不使用前端 60 秒快取，也不自動重送不確定的寫入。
- 接送明細 HTTP 404、權限錯誤與格式錯誤顯示「人數尚未確認」，不得儲存。
- 明細載入失敗仍可關閉；重試保留儲存後回呼並重新取得候選名冊。
- 舊版僅姓名的明細顯示唯讀，不將缺少學生編號誤當空白勾選。
- 候選名冊讀取失敗不快取成零人；過期視窗回應不得改寫新視窗。
- 不確定的明細儲存不得直接重送；不支援的舊清空操作暫停。
- 桌面錯誤畫面與手機候選名單截圖。
- 接送候選名單依學生編號連結主檔英文名，顯示「中文（英文）」；驗證主檔排序不同、姓名特殊字元、英文名空白與跨校快取共用。
- 新 Gateway 模式直接使用「學期班級指派!W」合併姓名，不额外請求學生主檔。
- 國小依 115-1 在學名冊去重產生，排除國中、幼兒園、離校、歷史與舊自訂清單。
- 既有非當期學校值保留但不可新選；接送中文／英文搜尋不取消已選學生。
- 學期指派列表使用合併欄位顯示與搜尋；名冊快取失效後讀回新姓名。

此測試證明前端流程與受控回應的處理，不代表真實使用者權限、正式後端延遲或寫入已完成驗收。

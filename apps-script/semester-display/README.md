# 學期班級指派：中英文姓名單一來源

## 狀態與範圍

Google「學期班級指派」W1:W2 已建立「學生中英文姓名」標題與自動合併公式。2026-09-22 讀回核對：74 筆 115-1 正確、51 筆歷史資料不填入新姓名；A:V 原有 22 欄及學生主檔均未變更。

此資料流為「學生主檔 C/D 欄 → 依學生編號對照 → 學期班級指派 W 欄 → semester_assignments_list → 指派搜尋與接送候選名單」。主檔改名與新增指派由公式自動反映，不維護第二份可手改姓名。

- 國小選項：115-1 在學名冊，學校名稱包含「國小」或「小學」，去除首尾空白並去重。
- 不納入國中、幼兒園、離校、其他學期，以及瀏覽器舊自訂學校。
- 排程既有但非當期國小的值保留顯示、禁止當作新選項，不改寫歷史排程。
- 姓名顯示與搜尋：直接使用 W 欄；學生識別仍用學生編號，並非合併文字。
- 合併欄位唯讀。所有既有 API 寫入仍只寫 A:V，不將 W 加進 `SEMESTER_ASSIGN_HEADERS`。
- 主檔、個別指派與整班調整送出後會清除接送名冊快取，下次進入或重新載入取得新資料。
- 不包括修復旧接送明細缺少學生編號、改寫歷史接送名單，或修改其他系統的資料契約。

- 重新整理[正式後台](https://admin.taipingxinguang.org/)，接送明細來源由「主檔相容模式」變成「W 欄『學生中英文姓名』」。

## 公式注意事項

W2 為單一陣列公式，範圍隨 C 欄最後一個學生編號增長；不用每列填公式，不把整張空白列算成有資料。不要手填 W3 以下，否則可能阻擋陣列展開。

公式僅作用於 115-1，歷史列保持空白；未來切換學期時需一併更新公式的學期條件與系統當期設定。W 欄不作為歷史姓名快照。

回退 Gateway 時，恢復原函式即可；原 22 欄完全相容。不要刪除原名冊，也不要用合併姓名替換學生編號。
